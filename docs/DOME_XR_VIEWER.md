# Quest 穹顶 VR 模拟器（`/xr`）

> **一句话定位：在 Quest 3 头显里"坐进"虚拟球幕影厅，直接检查 domemaster
> 母版（图片/视频）的映射效果——天顶在哪、正前方在哪、外圈会不会被压扁、
> 边缘黑边、画面拉伸。不装 App，浏览器输个网址就能看。**

这是 issue #434 的交付。它复用 `studio/dome_proj.js` 的投影公式（穹面 3D 预览
和已发布 fulldome 路线共用同一套数学），所以你在 Quest 里看到的穹顶和
Studio 2D 预览、和最终投到真球幕上的效果，是同一个映射——不是第三份拷贝。

## 两种访问方式

### 方式 1：USB（推荐，零配置）

`localhost` 是安全上下文，WebXR 可用，所以 USB 隧道下 **不需要 https**。

```bash
# 1. 启动 Studio（默认 127.0.0.1:8787，http 即可）
python -m studio.server

# 2. Quest 用 USB 连到电脑，开开发者模式，然后建反向端口隧道
adb reverse tcp:8787 tcp:8787

# 3. 在 Quest 浏览器（Meta Quest Browser / Wolvic）打开
#    http://localhost:8787/xr
```

进入页面 → 选母版 → 点「进入 VR」→ 戴上头显环顾。

### 方式 2：Wi-Fi（电脑 IP 访问）

WebXR 必须 https。自签证书用 openssl 生成到 work_root（Git for Windows 自带
openssl，不新增 Python 依赖）。

```bash
# 1. 带 --https 启动（监听所有网卡，Quest 用电脑 IP 访问）
python -m studio.server --host 0.0.0.0 --https

# 2. 在 Quest 浏览器打开（把 <电脑IP> 换成你电脑的局域网 IP）
#    https://<电脑IP>:8787/xr
#    首次点「继续访问 / Advanced → Proceed」过自签证书警告。
```

证书文件落在 `<work_root>/dome_xr_cert.pem` 与 `dome_xr_key.pem`，重启复用
（不重新生成），所以 Quest 上"继续访问"的例外记录一直有效。

> **openssl 不在 PATH 上时**：`--https` 会直接报错并提示改用 USB 方式
> （`adb reverse ...`），不会静默失败。Mac 上 `brew install openssl` 或直接
> 用 USB 方式即可。

### 访问方式对照

| | USB（`adb reverse`） | Wi-Fi（`--https`） |
|---|---|---|
| 需要 https | ❌（localhost 是安全上下文） | ✅ |
| 需要证书 | ❌ | ✅（openssl 自签） |
| Quest 上打开 | `http://localhost:8787/xr` | `https://<电脑IP>:8787/xr` |
| 首次点"继续访问" | 否 | 是（自签证书） |
| 推荐度 | ⭐ 零配置首选 | 电脑/Quest 不便连线时用 |

## 选片页（进 VR 前）

页面 `/xr`（`studio/static/xr/dome_xr.html` + `dome_xr.js`，原生 WebGL + WebXR，
无 CDN）左侧是选片面：

- **母版列表**：`GET /api/xr/sources` 只读列出 work_root 下最近的
  studio_out 图片/视频（最新在前），加上 `?src=<路径>` 指定的母版。
- **上传**：复用 `POST /api/upload`（拖文件到「⬆ 上传母版」即可）。
- **穹顶倾角**：`0° 天象馆 / 15° / 30° 倾斜影院 / 自定义`。
- **座位**：`中心（球心） / 后排（1/3 半径） / 前排`。
- **穹顶半径**：默认 8 m。
- **「进入 VR」大按钮**：选好母版后点亮。

## 手柄操作（Quest）

进入 VR 后，手柄映射如下；无手柄（手势模式）**捏合 = 播放/暂停**。

| 操作 | 功能 |
|---|---|
| 扳机 / A | 播放 / 暂停 |
| 摇杆左右 | ±5 s |
| 摇杆上下 | 倾角 ±5° |
| B | 叠加层开关 |
| 握把 | 切换座位 |

键盘（2D 模式同样可用）：`B` 叠加层、`空格` 播放/暂停、`←/→` ±5 s、
`↑/↓` 倾角 ±5°。鼠标 / 触摸拖拽 = 环顾。

## 检查叠加层（B 开关）

叠加层画在穹顶内表面，用来核对映射：

- **仰角圈**：15° / 30° / 45° / 60° / 75°。
- **方位线**：每 30° 一条；**正前方标一条红线**。
- **"舒适观看区"**：仰角 20°–60° 半透明绿色带。

## 倾角 / 座位对观感的影响

- **倾角 0°（天象馆）**：穹顶顶点在正头顶，抬头看天。母版圆心 = 天顶，
  正前方 = 母版圆下方（DECISION_DOME 约定）。
- **倾角 15° / 30°（倾斜影院）**：穹顶向后倾，顶点偏向身后，正前方变成
  "看银幕"的自然姿态——这正是倾斜球幕影院的几何。倾角越大，母版圆心越偏
  向身后，画面越像"前方大银幕"。
- **座位中心**：坐在球心，穹顶对称铺满视野，适合检查整体映射。
- **后排（1/3 半径）**：往后坐，前下方画面被前排边沿切，更接近真实观众视角。
- **前排**：往前坐，身后画面变小，前方画面放大——用来检查前方可读性。
- **穹顶半径**：8 m 是参考值。改大 → 穹顶离你更远（画面更"远"），改小 →
  贴脸（画面更"近"、更包覆）。半径只影响空间感，不影响映射公式。

## 非头显浏览器（电脑 / 无头）

同一页面在无 WebXR 的浏览器里自动进 **2D 环视模式**：在 `<canvas>` 上用鼠标
拖拽环顾、用键盘快捷键控制，渲染同一套着色器。这用于 lead 的无头 Chrome
自动化验收（`/xr?src=<测试 domemaster>` 截图核对"正前方为母版圆下方内容、
仰视看到圆心内容"），以及电脑上预览。

## 映射公式（与 Studio 2D 预览对拍）

片元着色器按视线方向算母版 UV，公式抽出为纯函数
`studio/static/xr/dome_xr_proj.js::dirToUV`，与
`studio/dome_proj.py::dir_to_master_uv` 在 5 个方向（天顶 / 正前 / 右 / 后 /
45°仰角）上对拍误差 < 1e-3（`tests/test_studio_xr.py`）。约定：

- 帧：`x` 右、`y` 上、`z` 前（观众正前方 = `+z`）。
- domemaster 约定（DECISION_DOME）：圆心 = 天顶，圆周 = 地平线，**圆下方
  = 正前方**。
- `r = 天顶角 / 90°`（方位等距）；视角方位角从正前向 `+x` 走，圆心横向位移，
  所以 `u = 0.5 + 0.5·r·sin(φ)`、`v = 0.5 + 0.5·r·cos(φ)`。
- 地平线以下（天顶角 > 90°，圆外）画深灰地面 + 座椅环，给影厅空间感。

## 已知限制

- **自签证书**：Wi-Fi 方式下 Quest 首次需手动"继续访问"；证书是自签的，
  浏览器会提示不安全，这是预期行为。
- **无立体**：这是**穹顶映射模拟器**，不是 VR180 立体播放器。domemaster 是
  单目 mono；本工具是给 owner 检查母版映射用的，不是最终头显观看体验。
  立体头显观看请走 `vr180` 路线。
- **视频纹理**：视频用 `<video>` 纹理逐帧上传； Quest Browser 的 WebGL
  视频纹理在某些编码下可能掉帧——优先用 H.264 mp4。
- **`/api/xr/sources` 只列 work_root 内文件**：不扫描仓库根、不列
  `video/` `models/` `.venv/`（边界锁）。要检查这些目录下的母版，先上传或
  拷到 work_root，或用 `?src=<work_root 内绝对路径>` 指定。
- **单眼渲染**：当前 VR 每帧对每只眼睛分别 draw 同一场景（正确双目投影
  由 headset pose 提供）；座位偏移合成在参考空间 pose 上。
- **openssl 不在时**：`--https` 报错并提示 USB 方式；不会静默降级到 http
  暴露在 0.0.0.0。
