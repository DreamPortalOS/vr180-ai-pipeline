## 生命周期规则

1. 每次测试开始前，建立唯一任务名和日期，并把文档、输出目录、过程缓存、真机文件名写入本索引。
2. 过程文件放在 `video/<task-id>/` 或系统临时目录，不放在仓库根目录；深度缓存、帧序列和中间编码不作为交付物。
3. 测试文档必须包含：输入、命令、输出文件、验收人、结论、后续动作和清理状态。
4. 只有同时满足“验收已完成、决策已记录、后续方案已确定、无当前引用”四项时，才可以删除测试文档及其过程资产。
5. 删除时按任务整组删除：测试单、样片、JSON/sidecar、帧序列、深度缓存和临时目录一起处理，不只删大视频留下孤儿文件。
6. 当前方案的参考样片保留到下一阶段验收完成；被明确否决的方案可以立即清理。
7. `video/` 仅用于本地素材和交付物，全部忽略，不提交媒体、模型、缓存或生成结果到 Git。
8. 删除前运行一次引用扫描，并在本索引留下日期、范围和决策依据；删除后运行测试与 `git status` 复核。
9. 任何无法证明已结束的文件标记为 `保留待确认`，不得仅凭文件名或修改时间删除。
