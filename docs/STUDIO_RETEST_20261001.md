## T1：先完成基本手工工作流

1. 从当前主线独立检出启动 Studio；记录 `/api/health`。未配置生图服务时必须明确警告；占位图不能算真实生图通过。
2. 添加手工分镜板，输入 prompt，生成 1–4 候选图（服务已配置时）或上传一张图，选中图片。
3. 设置时长、运动并生成每镜视频，播放后按顺序拼接。当前视频是静态图片运动，不能验收为真实生成视频。
4. 存库、刷新、重新打开：分镜内容、选图、顺序、时长、运动均恢复。
5. 运行期间打开队列，用 X、Escape、点外部关闭，轮询不得强制重开。
6. 仅运行中的任务显示取消；完成/失败任务显示准确终态，清理已结束任务不得清除运行中的任务。
7. 生产模板运行、二次 cache hit、仅重跑下游、导出文件另按原清单验证；各路径分别回填，不能由手工分镜通过推导生产模板通过。

## T2：视频、方向、覆盖度与布局

1. 3D 面板加载图片及视频，播放/暂停/定位可用；队列不得挡住面板。
2. 向左拖动右栏左边缘应增大右栏，画布随布局缩放，无溢出。
3. 方位参考、相机视口、倾角调整与实际母版方向一致，标出正前方与天顶。
4. 坏母版约 54° / r≈0.6；合规样例 ≥85°。记录实际值与输入，不只写“看起来正常”。
5. dome 分镜只允许固定或绕天顶旋转；平移/推拉不能破坏圆边。平面画幅单独验证运动。
