# Fulldome 输出使用说明

> ⚠️ **一句话定位：fulldome 是给球幕投影 / 桌面鱼眼播放器用的，不是 VR 头显格式。**
> 头显（Quest / Vision Pro 等）请用 `vr180` 输出。

## 什么是 fulldome / domemaster

`--projection fulldome` 产出的是 **domemaster** 格式：

- **方形画布内嵌圆形鱼眼**（如 2048×2048，圆外区域为黑边）。
- 投影方式为 **azimuthal-equidistant（方位等距）**：画面中心 = 天顶（头顶），
  圆周 = 地平线，角度从天顶向外线性展开。
- 默认 FOV 180°（`--dome-fov` 可调，最大约 220°），**单目（mono）**，无左右眼。

这是天文馆 / 球幕影院行业的标准母版格式，投影机 + 鱼眼镜头（或球幕镜）
把它投到半球幕上，观众抬头看。

## 适用场景

| ✅ 适用 | ❌ 不适用 |
|---------|-----------|
| 球幕影院 / planetarium 投影 | VR 头显（Quest、Vision Pro、PICO 等） |
| 桌面鱼眼播放器预览 | 任何期待"环绕立体沉浸"的头显观看 |

### 为什么不适用于 VR 头显

domemaster **没有立体（左右眼）信息，也没有 VR 元数据**（无 `sv3d`/`st3d`、
无投影类型标记）。头显播放器拿到一个方形鱼眼视频时，无法识别它的投影方式，
只会按默认规则处理 —— Quest 实测会把它当成 **"360° 2D 宽屏"** 播放
（WORKLOG 2026-06-27 反馈）：画面被错误拉伸、无立体感、视角混乱。

头显观看请使用路线2输出：`--projection vr180`（默认），即双眼 SBS 等距投影 +
`sv3d`/`st3d` 元数据注入，头显能正确识别为 VR180 3D。

## 怎么预览

**桌面鱼眼 / 球幕预览播放器**（任选其一）：

- **Amateras Dome Player**（Windows/Mac，天文馆常用）
- **Blendy Dome VJ** / **Resolume**（VJ / 球幕映射）
- 任何支持 domemaster 输入的球幕映射软件

**快速检查画面内容**（不看投影效果，只确认画面没坏）：

```bash
ffplay output_fulldome.mp4
```

ffplay 会把方形鱼眼原样显示为平面图（圆底画面），适合检查渲染是否成功、
内容是否正确，**不代表球幕实际观感**。

## 与 VR180 输出对照

| 维度 | fulldome（domemaster） | vr180（默认） |
|------|------------------------|----------------|
| 格式 | 方形画布 + 圆形鱼眼，azimuthal-equidistant | SBS 等距柱状投影（equirectangular 180°） |
| 观看设备 | 球幕投影 / 桌面鱼眼播放器 | VR 头显（Quest / Vision Pro / PICO） |
| 立体 | 无（mono） | 有（左右眼 3D） |
| 元数据 | 无 VR 元数据 | 注入 `sv3d` / `st3d`，头显可识别 |
| 管线阶段 | 跳过深度/立体/等距/元数据 | 全链路：深度 → 立体 → 等距 → 元数据注入 |
